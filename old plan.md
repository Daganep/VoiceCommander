# План: голосовой ассистент для Windows (офлайн)

Требования: офлайн-распознавание голоса; управление = окна + кнопки + ввод текста;
чтение = текст на экране (OCR); каждое действие озвучивается и пишется в лог.


## 1. Что делает и как
- Распознавание голоса (офлайн)     -> Vosk + русская модель (локально, без сети)
- Запуск приложений                -> subprocess / os.startfile + реестр псевдонимов
- Закрытие приложений              -> psutil (найти процесс по имени -> завершить)
- Управление окнами                -> pywinauto / pywin32 (свернуть, развернуть, на перед, закрыть)
- Нажать кнопку                    -> OCR находит текст кнопки на экране -> клик по координатам (pyautogui)
- Ввести текст в поле              -> найти поле (OCR по метке / UIA) -> клик -> набор клавиатуры
- Чтение текста с экрана           -> OCR (Tesseract / PaddleOCR) по скриншоту
- Озвучка действий и результатов   -> pyttsx3 (SAPI)
- Логирование                      -> Python logging -> файл (ротация) + консоль

Ключевая идея: OCR — общий механизм для чтения экрана, нажатия кнопок и поиска полей.
Говорим «нажми Ок» -> видим «Ок» на экране -> кликаем туда.


## 2. Библиотеки
- Vosk                 - распознавание речи (офлайн, быстрая). Альтернатива: faster-whisper
- PyAudio              - захват микрофона
- pyttsx3 (SAPI)       - озвучка (без установки). Альтернатива: Piper (натуральный голос, +60 МБ)
- psutil + subprocess  - запуск/закрытие процессов
- pywinauto + pywin32  - управление окнами и UI
- pyautogui + Pillow   - клик, набор текста, скриншот
- pytesseract          - OCR (движок Tesseract, есть русская). Альтернатива: PaddleOCR (точнее)
- pynput               - глобальная клавиша push-to-talk
- pystray (опц.)       - иконка в трее (старт/стоп)
- pyyaml               - конфиг


## 3. Устанавливается один раз
- Tesseract OCR + русский язык (rus.traineddata)  [через winget]
- Модель Vosk: vosk-model-small-ru-0.22 (~45 МБ)  -> папка models/
- Остальное через pip (виртуальное окружение)


## 4. Структура проекта
voice_commander/
  requirements.txt
  config.yaml            # язык, голос, псевдонимы приложений, движок OCR, подтверждения
  voice_commander.py     # точка входа, главный цикл
  core/
    speech/
      stt.py             # Vosk
      tts.py             # SAPI
    commands/
      parser.py          # «нажми Ок» -> объект Command
      schema.py          # описания команд
    actions/
      launch.py          # запуск
      close.py           # закрытие
      window.py          # окна
      ui_click.py        # клик по кнопке (OCR -> координаты)
      ui_type.py         # ввод текста в поле
      screen_ocr.py      # чтение текста с экрана
    ui/
      automation.py      # pywinauto
      ocr.py             # tesseract/paddle -> слова + координаты
      coords.py          # pyautogui (клик/набор)
    apps/
      registry.py        # «блокнот» -> notepad.exe
      processes.py       # psutil
    feedback.py          # ЕДИНАЯ точка: «скажи + запиши в лог»
    logger.py            # настройка логирования
  models/                # Vosk-модель
  logs/                  # логи

Принцип: каждое действие возвращает результат -> feedback.py делает ровно одно —
озвучивает и логирует.


## 5. Цикл работы
ИДЛЕ -> (нажали клавишу / wake-слово) -> СЛУШАНИЕ (Vosk) -> распознана фраза
     -> ПАРСИНГ -> Command -> ИСПОЛНЕНИЕ -> РЕЗУЛЬТАТ -> озвучить + лог -> ИДЛЕ

- Push-to-talk (рекомендую): зажмите клавишу (напр. Ctrl+Alt+V) -> говорите -> отпустите -> команда.
- Альтернатива: постоянное слушание + wake-слово «компьютер, ...» (опционально).
- Таймаут / не понял -> «Не понял, повторите».


## 6. Словарь команд (русский)
- Запуск:   «открой блокнот», «запусти браузер»
- Закрытие: «закрой блокнот», «заверши процесс»
- Окна:     «сверни», «разверни», «на перед», «верни в норму»
- Кнопка:   «нажми Ок», «нажми кнопку Сохранить», «кликни Да»
- Ввод:     «введи текст ...», «введи ... в поле Логин»
- Экран:    «прочитай экран», «что написано на экране»
- Служебные: «стоп», «повтори», «выход»

Неоднозначность: если совпадений несколько -> озвучить варианты и попросить уточнить.


## 7. Безопасность и ошибки
- Подтверждение разрушительных действий (закрытие): «Закрывать Блокнот? Скажите «да»» (флаг в конфиге).
- Глобальный try/except в цикле: одна неудачная команда не роняет приложение.
- Ошибки (нет приложения / не найден элемент / OCR пуст) -> понятное сообщение вслух + лог.
- Текстовый режим (--text): команды с клавиатуры вместо голоса — для тестов без микрофона.


## 8. Поэтапный план работ
0. Каркас            -> проект, venv, зависимости, конфиг, логгер, feedback, текстовый REPL
1. Голос             -> Vosk STT + SAPI TTS + цикл push-to-talk (говорю -> слышу -> отвечаю вслух)
2. Запуск/закрытие   -> реестр псевдонимов, launch/close («открой/закрой блокнот» работает)
3. Окна              -> свернуть/развернуть/на перед/закрыть окно (на 2-3 реальных окнах)
4. OCR-чтение        -> скриншот -> Tesseract -> озвучка текста («прочитай экран»)
5. Кнопки и поля     -> клик по тексту кнопки; ввод в поле («нажми Ок», «введи ... в поле»)
6. Полировка         -> неоднозначности, подтверждения, UX ошибок, иконка в трее, .exe, документация

Этапы 0-4 = рабочий MVP; 5-6 = полный функционал и «упаковка».


## 9. Решения по умолчанию (можно поменять)
1. Режим запуска: push-to-talk клавишей (рекомендую). Альтернатива — постоянное слушание с wake-словом.
2. OCR-движок: Tesseract (лёгкий). Альтернатива — PaddleOCR (точнее, тяжелее).
3. Голос озвучки: SAPI (без установки). Альтернатива — Piper (натуральный, +60 МБ).
4. Подтверждения на закрытие приложений: включены.
